# AVL Tree

一个使用 C++ 模板实现的 AVL 树数据结构练习。核心代码位于 `AVL_Tree/AVL_Tree.hpp`，包含节点定义、插入、平衡旋转和遍历方法；Visual Studio 工程入口目前是一个空的 `main()`。

## 实现内容

- 模板化的 AVL 节点与树结构，可存储支持大小比较的类型。
- 按大小插入元素，并编写了 LL、RR、LR、RL 四种旋转逻辑。
- 提供前序、中序、后序和层序遍历，遍历结果输出到控制台。
- 提供递归高度计算、交换左右子树和析构释放节点的方法。
- 相同键值不会重复插入；当前没有查找和删除接口。

## 当前状态与限制

这是一个数据结构练习草稿，尚未整理成可直接演示的程序：

- `AVL_Tree/main.cpp` 只包含头文件并返回 0，因此直接运行没有输出。需要在入口中创建 `AVLTree<T>` 并调用插入、遍历等方法来演示。
- 四个旋转辅助函数声明为返回节点指针的引用，但返回的是局部指针变量的引用。触发旋转时行为未定义，使用前应修正接口并验证 LL、RR、LR、RL 情况。
- 公共方法 `hight()` 调用了递归高度计算，但没有返回计算结果；目前不要依赖它的返回值。
- `exchange_child()` 会递归交换所有节点的左右孩子，适合作为镜像操作示例；调用后树不再保持二叉搜索树的排序关系。

## 环境与构建

- Windows
- Visual Studio 2022 / MSVC v143
- 无第三方库依赖

打开仓库根目录中的 `AVL_Tree.sln`，选择 **Debug | x64**，然后在 Visual Studio 中生成并运行。当前入口程序没有演示逻辑，因此运行时不会打印遍历结果。
